# 📰 News API JS Project

A simple web application that fetches and displays the latest news using a News API. Users can browse news articles by category or search for specific topics.

---

## 📌 Features

- 📰 Fetch latest news articles
- 🔎 Search news by keywords
- 📂 Category-based news filtering
- ⚡ Simple and fast UI
- 📱 Responsive design

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  
- News API  
- GitHub Pages (Deployment)
